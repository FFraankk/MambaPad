## 1.2.1-preview 手势调整

- 去掉系统长按与 500ms 定时器自动按住左键的逻辑。原先单指停留后移动会进入选中/拖动，这是容易误触的触发来源。
- 第一次轻点立即单击；第二次快速按下时按住左键，移动拖动，抬起或取消时释放。单纯滑动和停留不按住左键。
- 滚轮按钮本身支持上下拖动，向下移动发送负垂直滚轮值（Windows 向下），向上发送正值。保留按住滚轮并滑动触控区的用法，两个区域各自跟踪指针基线。
- Android 构建与 15 项 JVM 测试通过。真机自动回归通过停留后移动不选中、轻点后拖动、快速双击、取消释放、滚轮按钮和触控区的上下方向，以及拖动中指针顺序切换无跳跃；系统输入法、横竖屏、返回和生命周期重连回归均通过。辅助包已移除。
- EXE 协议无变化，1.2.0-preview 的 Windows 接收端可以继续使用。尚未发布新的 GitHub Release。


## 1.2.2-preview 桌面框选

在自建 Windows ListView 中通过现有接收端复现：普通按住拖动选中 8 个图标，先单击再快速按下拖动选中 0 个，分类后仅发送普通拖动选中 8 个。未移动真实桌面图标。

原因是 Windows 会把第二次快速按下转换为 WM_LBUTTONDBLCLK，列表框选需要 WM_LBUTTONDOWN 的拖动流程。手机端改为先判定：第一下暂缓，第二下移动后发送 DOWN，松开 UP；第二下不移动而松开时发送两个完整 CLICK。单击延迟采用 Android 系统 double-tap timeout，取消或断线不遗留等待点击。

构建与 JVM 20 项测试通过，覆盖拖动前不发送额外单击、双击保留、过期单击确认不污染拖动、取消释放。用户已确认真实 Windows 桌面空白处框选恢复正常；最新版本整套真机自动回归未重跑。无需修改 EXE 或系统双击设置。
