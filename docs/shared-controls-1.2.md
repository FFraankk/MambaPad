# MambaPad 1.2 preview 验证记录

2026-11-24，小米 10 / Android 11，USB 接收端配套新版。

- 主页 USB / 蓝牙独立入口，共用控制页面。
- 纯触控横竖屏、键盘横屏左右分区、竖屏系统输入法。
- 真机 Instrumentation 通过：四种布局、USB/蓝牙按钮返回、蓝牙 Android 返回、生命周期重连、拖动指针重排无跳跃。
- 原生输入连接通过：拼音 composing 不发送，中文与表情 commit 发送，表情按码点删除，finishComposingText 提交。
- 模拟可用高度 340 / 440 / 600 dp：触控板随高度增长，鼠标按钮与输入框保持可用；真机截图确认当前讯飞输入法可见且不遮挡触控区。
- 横屏快捷键 Alt+A、Win+R、普通 B 验证无修饰键残留。JVM 单测 15 项，Go 单测和 vet 通过。
- Windows Unicode 协议单测通过；用户已在真实电脑应用中确认中文、英文、回车、退格及键盘高度适配正常。
- 完整 Android lint 尚有 41 个既有错误，主要为旧蓝牙代码权限静态检查；新增共享页面、系统输入框和新 HID sender 无 lint 错误。没有屏蔽错误或生成 baseline。
- 蓝牙本轮验证 UI 和返回流程，尚未完成真实电脑配对后的端到端输入测试。

文字不写入持久存储、不读取剪贴板。USB 中文/表情需新版 EXE；蓝牙 HID 只有键盘按键通道，手机已选好的汉字暂不能直接发送，需电脑输入法。

输入法为悬浮模式时，遮挡区域由输入法管理；本应用不修改输入法或系统设置。不同品牌/输入法尚未逐一验证。

主页横屏改为左右两栏：左侧品牌说明，右侧 USB / 蓝牙入口；缩短顶部和卡片间距，保留小屏滚动兜底。
