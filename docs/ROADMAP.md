## 1.2 基线（2026-11-24）

- 已发布：[v1.2.2-preview](https://github.com/FFraankk/MambaPad/releases/tag/v1.2.2-preview)。Android versionCode 8，debug 签名；Windows EXE 未签名。
- USB 触控、键盘、系统输入法中文/英文/表情，横竖屏与返回页面可用。
- 普通移动不误选中；滚轮按钮直拖；桌面框选已由用户确认修复。
- JVM 20 项通过。1.2.1 完整设备回归通过；1.2.2 通过 Windows 临时图标列表对比和用户真实桌面验证，最新整套设备自动回归未重跑。
- 完整 Android lint 最近记录为 41 个既有错误，主要涉及旧蓝牙权限与常量；新增任务需重新看报告，不能把这个数字当作永久允许值。
- 当时的测试接收端已按用户要求关闭；当前设备及进程状态见 HANDOFF，不为文档检查重新启动接收端。

## 当前版本：1.3.0 正式版（2026-11-25）

- [1.3.0](https://github.com/FFraankk/MambaPad/releases/tag/v1.3.0) 已正式公开并设为 Latest，versionCode 10；旧预览版保留。

- 功能源码的 Android 构建／20 项 JVM／Mi 10 应用内真机回归、Windows Go test/vet、设备选择和托盘行为已验证；正式附件已完成身份、签名、版本与哈希核验。真实安装／覆盖升级／卸载验证来自先前预览版，不等同于正式附件重跑。
- 发布及当前验证边界见 [交接记录](HANDOFF.md)；先前触觉与安装测试见 [1.3 预览验证记录](desktop-haptics-1.3.md)。
