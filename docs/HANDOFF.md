## 已确认行为与验证边界

- USB 触控、系统输入法中文/英文/表情、横竖屏、返回与主页横屏已有用户确认。
- 滚轮按钮直拖，下滑向下、上滑向上；普通停留不自动选中。
- 轻点后快速第二下滑动是普通按住拖动；不提前发送第一下 CLICK，避免 Windows 桌面误识别为双击。单击延迟是有意取舍。
- JVM 20 项通过。Windows 临时 ListView 对比与用户真实桌面验证通过；1.2.2 最新整套真机自动回归没有重跑。
